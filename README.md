# Markdown Editor Plus

![image](https://github.com/mcv-s/mcv-s.github.io/blob/main/portfolio-images/MDEP-Wide.png?raw=true)

Markdown Editor+ is a markdown editor supporting inline html, images, links, and standard markdown features. 

It was created to replace the windows notepad - although it may replace other tools as well. 

All files stay on your device. 

# Features

Some useful features:

-   Privacy
-   Raw and Inline editing
-   Resizable work surfaces
-   Local file loading and saving
-   A PWA (Progressive Web Application) with direct file opening
-   Light and Dark mode
-   Inline HTML Interpretation
-   No accounts
-   Persistent editor preferences

# PWA

One of the most useful features of Markdown Editor+ is the PWA (Progressive Web Application)

It lets you install the app directly to your device so markdown editing is never a hastle again.

On Edge (and probably chrome) + Windows, files can be opened directly throught the PWA.

# Browser Support

Markdown Editor+ is designed for Chromium-based browsers such as Chrome and Edge.

Some functionality, particularly direct file access, depends on browser support for the File System Access API.

Certain features may not work on other browsers - such as Safari or Ladybird.
